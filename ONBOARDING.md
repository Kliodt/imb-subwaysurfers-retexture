Статусы:
- **Перерисовано; ожидает сборки** — PNG установлен и проверен локально, общая сборка ещё не выполнена.
- **Не начато** — новый вариант ещё не установлен в рабочий PNG.
- **В работе** — агент начал редактирование; в примечании указать, что осталось.
- **Собрано; проверить в игре** — PNG установлен, сборка и проверка RGBA прошли, визуальная проверка ещё не завершена.
- **Нужна правка** — обнаружена проблема; записать конкретный дефект.
- **Готово** — проверены размер, альфа, сборка и реальное отображение в игре.
- **Оставить исходным** — после осмотра подтверждено, что менять файл не требуется; обязательно объяснить причину.

## Важные ограничения

- НЕ запускай `export`: он перезапишет все рабочие PNG оригиналами.
- `demo` не собирает пользовательские PNG и создаёт старую фиолетовую перекраску.
- НЕ восстанавливай текстуры через git restore без необходимости и сохранения новых правок.
- Исходные PNG доступны в коммите `a9cdde1`; читать их можно без изменения рабочего дерева. Локальные резервные копии четырёх атласов также в `output/originals/`.
- Для сборки используется чистый исходный пакет, затем применяются изменённые PNG. game-local исключён из Git: после переноса/отката сборку надо повторить.
- Иконки персонажей не являются доказанными текстурами 3D-персонажа; для одежды сначала исследовать Material → Texture2D и renderer.
- Не менять исходный репозиторий, SDK, механику и прочие текстуры без связи с задачей.

## Проверенный маршрут генерации в этой Windows-сессии

Локальные `referenced_image_paths` генератор не видит: Windows-путь отклоняется с AbsolutePathBuf, `/C:/...` — unavailable. Рабочий обход: сначала показать целевой атлас через view_image, затем вызвать imagegen с `num_last_images_to_include: 1` без referenced_image_paths. Стиль задаётся по предварительно осмотренным exampleImages.

Результат imagegen приходит data URL. Не печатай base64 в ответ или tool output. Сохрани результат в functions store; для записи создай промежуточный `.b64` через apply_patch и затем коротким Python-скриптом декодируй, нормализуй размер и верни исходную альфу. Это техническая нормализация результата imagegen, не программная художественная замена генерации.

В этом запуске запись data URL через node_repl зависала более 15 минут у нескольких агентов. Не повторять этот маршрут: применить apply_patch к промежуточному файлу. Не передавать мегабайты base64 в shell command (лимит Windows) и не запускать сотни мелких shell процессов для записи одного изображения.
