## Запуск

Из корня проекта:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

Открыть [локальную сборку](http://127.0.0.1:8766/game-local/) и обновить Ctrl+F5. HTML нельзя открывать двойным щелчком через file://.

## Файлы и работа с текстурами

- `subway-original/` — исходная готовая Unity WebGL-сборка, не редактировать.
- `textures/` — 102 PNG и каталог размеров; 70 изображений изменены.
- `game-local/` — собранная версия новых текстур, исключена из Git.
- `game-demo/` — отдельная старая экспериментальная копия, не текущий результат.
- `.tools/python/` — локальные зависимости UnityPy/Pillow.
- `scripts/recolor_ui_atlases.py` — точная программная перекраска двух плотных UI-атласов, выбранная пользователем. Остальные изменения выполнены imagegen.

После правок PNG выполнить `python texture_tool.py build`. Сохранять размеры, альфу и расположение UV. **`export` перезаписывает все PNG оригиналами**; не использовать для обычных правок. `demo` создаёт отдельную старую пробную перекраску.

Для восстановления зависимостей: `python -m pip install --target .tools/python UnityPy==1.25.4`.

## Docker: сборка и nginx

Из корня проекта, при запущенном Docker Desktop в режиме Linux containers:

```powershell
docker build -t subwaysurfers .
docker run --rm -p 8080:80 --name subwaysurfers subwaysurfers
```

Игра: http://localhost:8080/ (в контейнере раздаётся содержимое game-local прямо из корня сайта).

Dockerfile устанавливает UnityPy1.25.4, пересобирает все текущие PNG и переносит готовую игру в nginx. Минимальные исходные ресурсы Zurich находятся в build-inputs/ (10 файлов, около54МиБ); эту папку обязательно включать в Git вместе с Dockerfile. Внутри Python-этапа она копируется как subway-original/, как ожидает texture_tool.py. Локальный исходный вложенный репозиторий subway-original/ для Docker теперь не нужен и исключён из контекста. После коммита и push build-inputs обычный git pull на сервере получает все необходимые ресурсы без SCP.

После изменения PNG остановить контейнер (Ctrl+C), снова выполнить docker build и docker run. Открытую страницу обновить Ctrl+F5. Для остановки фонового контейнера: docker stop subwaysurfers. Для запуска в фоне добавить -d к docker run.

nginx.conf не добавляет Content-Encoding к .unityweb: legacy UnityLoader самостоятельно обрабатывает сжатие этих файлов. Отсутствующие ресурсы возвращают404. Текстуры запекаются в образ при сборке; монтирование каталога textures в работающий nginx не обновит пакет Unity.
# Программный ввод

`window.isGameRunning()` возвращает true после PokiSDK.gameplayStart, false после gameplayStop и null до первого наблюдаемого события. Отслеживание автоматически включено в game-input.js и учитывает асинхронную загрузку/замену SDK. Это признак состояния по событиям Poki, а не точный детектор экрана: отправку gameplayStop при паузе нужно проверить в самой игре.

Для чтения цвета пикселя из консоли launcher-template.html включает preserveDrawingBuffer до создания WebGL-контекста. После обновления шаблона нужна полная перезагрузка страницы; уже созданный контекст изменить нельзя. Сохранение буфера может увеличить затраты на отрисовку. Для диагностики: gl.getContextAttributes().preserveDrawingBuffer должно быть true. readPixels читает текущий framebuffer: для экранного изображения должен быть выбран framebuffer=null.

Сочетания с Ctrl/Cmd, а также F5/F12 оставлены браузеру: они обходят keyPressed и не передаются Unity. Это сохраняет обновление страницы (Ctrl+R, Ctrl+Shift+R), адресную строку и DevTools.

Каждое физическое нажатие/отпускание и каждый `sendKey` проходят через синхронную функцию `window.keyPressed({key, isDown, repeat})`. `key` — физический код клавиши (`KeyA`, `Space`, `ArrowLeft`), `isDown` — `true` для нажатия и `false` для отпускания. По умолчанию функция возвращает объект без изменений. Её можно заменить в коде страницы или в консоли:

```js
window.keyPressed = ({ key, isDown, repeat }) => {
    if (key === "KeyQ") return; // Ничего не отправлять в игру.
    const mapping = {
        KeyA: "ArrowLeft", KeyD: "ArrowRight",
        KeyW: "ArrowUp", KeyS: "ArrowDown"
    };
    return { key: mapping[key] ?? key, isDown, repeat };
};
```

Если функция ничего не возвращает (`undefined`) или возвращает `null`, событие полностью блокируется. Возвращённый объект задаёт клавишу и тип события; исходное событие в игру не проходит. Для обычного ремапа одинаково обрабатывайте нажатие и отпускание, чтобы игра не получила зажатую клавишу без отпускания. Перехват работает после появления канваса, включая автоповтор; системные сочетания, которые браузер не передаёт странице, перехватить нельзя. Проверки: `node scripts/test-game-input.cjs`.

В консоли страницы игры доступен `window.gameInput`:

```js
await gameInput.sendKey("ArrowLeft", 80);
await gameInput.sendKey("Space", 50);
await gameInput.sendClick(200, 300, 50);
```

`sendKey(key, durationMs = 80)` принимает стрелки, Space, Enter, Escape, Tab, Backspace, ShiftLeft, ControlLeft, AltLeft, буквы (`a` или `KeyA`) и цифры (`1` или `Digit1`). Отправляет keydown и keyup. `sendClick(x, y, durationMs = 50)` отправляет mousemove, mousedown, mouseup и click левой кнопки; координаты отсчитываются от верхнего левого угла канваса в CSS-пикселях, независимо от внутреннего разрешения Unity.

Оба метода возвращают Promise и выполняются в общей очереди: параллельные вызовы не накладываются. Дождитесь загрузки игры перед вызовом. Ошибочные аргументы отклоняются; отсутствие канваса или координаты за его границами приводят к отклонению Promise. В фоновой вкладке таймеры могут задерживаться. События синтетические (`isTrusted=false`), поэтому разрешения браузера вроде fullscreen ими не активируются.

Реализация: `game-input.js`, подключение в `launcher-template.html`. Обычный build и Docker включают её автоматически. Проверены последовательность событий, длительности, legacy-поля Unity, координаты и восстановление очереди после ошибки. Реакция игры в забеге ещё не проверена.


`repeat` — boolean: true только для повторного keydown при удержании; false для первого нажатия, отпускания и sendKey. Его можно изменить в возвращённом объекте; если поле не возвращено, сохраняется входное значение. Например, `if (repeat) return;` блокирует автоповтор.
