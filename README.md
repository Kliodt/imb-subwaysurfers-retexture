# Subway Surfers — локальная версия и текстуры

`subway-original/` — исходный скачанный репозиторий, сохранён без изменений.
`textures/` — 102 изображения PNG и каталог с названиями и размерами.
`game-local/` — локальная сборка из PNG (сейчас без изменений).
`game-demo/` — проверочная сборка с розово-фиолетовыми поездами.
`.tools/` — установленные зависимости, нужны для работы с текстурами.

## Запуск

Из этой папки:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

Оригинальные текстуры: http://127.0.0.1:8766/game-local/

Тестовые поезда: http://127.0.0.1:8766/game-demo/

Открывать через локальный сервер, а не двойным щелчком по HTML.

## Изменение текстур

1. Измените нужный PNG в `textures/`, сохраняя размеры и прозрачность.
2. Выполните `python texture_tool.py build`.
3. Откройте `game-local/` через сервер и обновите страницу с Ctrl+F5.

`python texture_tool.py export` заново извлекает оригинальные PNG и перезаписывает изображения в `textures/`.
`python texture_tool.py demo` создаёт тестовую перекраску поездов отдельно от ваших PNG.

Для восстановления зависимостей: `python -m pip install --target .tools/python UnityPy==1.25.4`.

## Что проверено

Извлечены 102 PNG; тестовая текстура поездов изменена и сохранена в пакете ресурсов.
После повторного открытия пакета RGB-пиксели изменённой текстуры совпали, число объектов сохранилось (44406).
Тестовая сборка загрузилась в браузере до экрана даты рождения. Забег после этого экрана не проверялся.

Это перепаковка ресурсов готовой WebGL-сборки. Код игры и механика не перекомпилируются.
Ресурсы игры загружаются локально; встроенные сторонние SDK могут обращаться в интернет.
